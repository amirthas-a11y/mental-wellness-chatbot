# Wellness Buddy 🕺🏻 | Student Mental Health Companion

An AI-powered, empathetic chatbot designed specifically for students facing academic stress, hostel life challenges, and emotional hurdles. 

## 🚀 Why This Exists (Survey-Backed)
This project was developed based on a survey of **51 students**. Key findings that shaped this bot:
- **88.2%** face academic stress regularly.
- **70.6%** hesitate to talk to adults/parents about their problems.
- **56.9%** ranked **Privacy** as their top concern.

## ✨ Features
- **Buddy Persona:** Uses casual, empathetic language (English/Hindi/Bengali).
- **Ghost Mode:** One-click session erasure for 100% privacy.
- **Real-time Mood Tracker:** Visualizes emotional trends using VADER Sentiment Analysis.
- **Zen Mode:** Integrated 1-minute breathing exercises for immediate stress relief.
- **Hostel-Context Aware:** Specifically tuned to handle roommate and mess-life issues.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Chart.js
- **Backend:** Flask (Python)
- **AI Engine:** Google Gemini 2.0 Flash
- **Sentiment:** VADER Sentiment Analysis
- **Database:** SQLite (Lightweight history tracking)

## 📦 Installation
1. Clone the repo: `git clone <your-repo-link>`
2. Install dependencies: `pip install -r requirements.txt`
3. Set your API Key: `export GEMINI_API_KEY='your_key_here'`
4. Run the app: `python app.py`
